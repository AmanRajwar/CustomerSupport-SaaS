# Artillery Load Test - Quick Reference

## 🚀 TL;DR - Commands to Run

### Prerequisites
```powershell
# 1. Install Artillery globally (one-time)
npm install -g artillery

# 2. Verify Artillery
artillery --version
```

### Run Full Baseline Test (in Backend directory)
```powershell
# 3. Install project dependencies
npm install

# 4. Ensure .env has MONGO_URI set
# Example: MONGO_URI=mongodb://localhost:27017/customer-support

# 5. Start MongoDB (separate terminal)
mongosh  # or use MongoDB Compass / Atlas

# 6. Seed database with 50,000 tenants
npm run seed

# 7. Extract actual tenant IDs for load test
npm run extract-tenants

# 8. In new terminal, start backend server
npm start

# 9. In another terminal, run Artillery load test
npm run load-test

# 10. Generate HTML report
npm run load-test:report

# 11. Open in browser
artillery-report.html
```

---

## 📊 What Each Command Does

| Command | Purpose |
|---------|---------|
| `npm run seed` | Seeds MongoDB with 50,000 tenants + 50,000 widget configs |
| `npm run extract-tenants` | Exports 1,000 real tenant IDs from DB to `tenants.csv` |
| `npm run load-test` | Runs 60-second Artillery test (500 RPS target) |
| `npm run load-test:report` | Converts JSON report to visual HTML dashboard |

## 📈 Key Metrics (from Artillery output)

```
Mean latency:     65 ms      ← Average response time
p50:              42 ms      ← 50th percentile (median)
p95:              245 ms     ← 95th percentile (important!)
p99:              512 ms     ← 99th percentile (tail latency)
Error rate:       0.03%      ← % of failed requests
RPS sent:         499.95     ← Actual requests/second achieved
```

**Expected Results (No Cache):**
- p95: 800ms - 2000ms
- p99: 1500ms - 5000ms
- Error Rate: 0.1% - 0.5%

## ⚙️ Configuration Files

- **`artillery.yml`** - Load test config (60 sec, 500 RPS, CSV-driven tenantIds)
- **`tenants.csv`** - Real tenant IDs from database (auto-generated by `extract-tenants`)
- **`LOAD_TEST_GUIDE.md`** - Detailed metrics & troubleshooting

---

## 🐛 Common Issues

| Problem | Solution |
|---------|----------|
| "ECONNREFUSED" | Backend not running - run `npm start` |
| "MONGO_URI not set" | Add `MONGO_URI=...` to `.env` file |
| "No tenants found" | Run `npm run seed` first |
| "CSV file not loading" | Run `npm run extract-tenants` to populate tenants.csv |

## 💡 Pro Tips

- **More realistic test:** Adjust `think: 100` in `artillery.yml` to simulate user think-time
- **Increase load:** Change `arrivalRate: 500` to higher value
- **Longer test:** Change phase `duration: 60` to `duration: 300` (5 minutes)
- **Monitor live:** Run `db.serverStatus()` in another terminal to watch MongoDB metrics
- **Scale testing:** Run multiple Artillery instances from different machines for distributed load
